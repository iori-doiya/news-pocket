# ニュースポケットをiPhoneのホーム画面に追加する

2026年10月16日。iPhoneのSafari向けです。[Appleの公式手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)を確認して案内を作りました。iOSやSafariの表示設定でボタンの位置は変わります。

## 操作する順番

1. iPhoneでSafariを開き、`https://my-news-pocket.com/`を入力します。ニュースポケットの青い見出しとニュース一覧が表示されたら「共有」をタップします。共有ボタンが見えなければ、ページメニューから「共有」を選びます。
2. 共有の一覧を下へスクロールし、「ホーム画面に追加」を選びます。名前が「ニュースポケット」、アイコンが紺地の青いポケットと白いニュース用紙になっているか確認します。「ウェブアプリとして開く」が表示された場合はオンにし、確認画面の「追加」をタップします。
3. ホーム画面に「ニュースポケット」のアイコンが追加されます。そのアイコンからサイトを開きます。

「ホーム画面に追加」が見つからない場合は、共有の一覧の一番下の「アクションを編集」で追加できます。LINE等のアプリ内ブラウザで開いている場合は、先にSafariで開いてください。保存した記事を使うには、追加した画面でもGoogleログインが必要な場合があります。

## このサイトで設定したもの

- public/index.html：ホーム画面用アイコンと起動設定を読み込みます。
- public/apple-touch-icon.png：iPhone向け180×180のアイコンです。
- public/manifest.webmanifest：サイト名、開始URL、表示方法、アイコンをまとめた設定ファイルです。開始はホーム一覧、表示はstandalone（通常のブラウザ枠を省いて開く指定）です。
- public/icon-192.png・icon-512.png：192×192・512×512のアイコンです。
- docs/images/news-pocket-icon-master.png：新しいアイコンの原寸画像です。内蔵image_genで作成し、PC同梱のSharpで配信用PNGを縮小出力しました。生成指示はnews-pocket-icon-prompt.txtに保存しています。古いapp-icon.svg・favicon.svgは履歴用で、現在のホーム画面やトップページでは読み込みません。
- public/favicon-32.png：ブラウザ用32×32のアイコンです。
- public/home-screen.html：設定画面の「ホーム画面に追加」から開く短い操作案内です。

ニュース表示・ログイン・保存はこれまでと同じサイトへ接続します。オフライン保存やプッシュ通知の仕組みは追加していません。

アイコンをすでに追加していて古い画像が残る場合は、ホーム画面のアイコンだけを取り除き、サイトをSafariで開いて追加し直してください。サイトのアカウント削除やブラウザのデータ削除は不要です。

## 作成した案内画像と確認範囲

内蔵image_genで、添付の雰囲気を参考に3ステップの案内画像を作成しました。このPCの作業フォルダのdocs/images/iphone-home-guide.pngに保存しています。使用した全文の指示は同フォルダのiphone-home-guide-prompt.txtです。これらの案内画像・生成指示は今回のローカル保存用で、GitHubへは含めていません。

画像は操作説明のためのイメージで、iPhone実機で撮影・操作したものではありません。アイコンのPNG寸法と形式、manifestの読み込み、公開ファイルの応答は検証報告に記録します。iPhone実機での追加・単独表示・Googleログインの復帰は未確認です。

公開確認：eba09494-8a05-4e39-88e1-3b4f3c7e24f7で、manifestと3サイズのPNGがHTTP 200で取得でき、日本語のサイト名・開始URL・standalone指定が一致しました。既存の7記事とGoogle・D1設定も応答しています。これは公開ファイルの確認で、iPhone実機での操作成功とは区別します。
