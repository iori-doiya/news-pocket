## 有効化する前に記録する項目

`config/sources.json` の媒体ごとに、次の5つを別々に確認する。確認できない項目はfalseを維持する。

| 設定項目 | 確認する範囲 |
|---|---|
| rights.collect | 公式RSSから、見出し・URL・日時などを取得できるか |
| rights.display | 不特定の利用者に見出し・媒体名・日時・リンクを公開できるか |
| rights.body | RSSで配信された本文・抜粋を取得し、一時処理できるか |
| rights.aiInput | その本文・抜粋をCloudflare Workers AIへ入力できるか |
| rights.summary | 生成結果を公開・再利用・保存できるか |

この実装はWebページの本文スクレイピング（HTMLから記事全文を抜き出す処理）を行わない。RSSの本文・抜粋だけを使う。RSSに全文がなければ全文要約は作れない。本文の利用が不可の場合は本文を解析結果へ取り出さず、要約も作らない。

確認記録は次の書式でこの文書に追記する。許諾メールに個人名や秘密情報がある場合は公開リポジトリへ貼らず、非公開の保管場所で管理し、ここには必要な判断結果だけを残す。

```text
媒体名：
確認日：
根拠の公式URL：
許諾を受けた用途・範囲（公開一覧／保存／AI入力／要約提供）：
出典・リンク・表示文言の必須条件：
保存期限（記事情報／生成結果）：
保存済み記事の継続保持は可能か：
更新・撤回時の対応：
6テーマのうち供給できるテーマ：
判断：無効の維持／見出しのみ有効／AIも有効
```

許諾条件がこの実装の表示方法・保存方式と合わない場合は、コードを修正して条件を満たすまで有効化しない。単にフラグをtrueへ変えるだけでは許諾を取得したことにはならない。
