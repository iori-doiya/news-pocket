## 記事を開いた本文の詳しさ（10月16日の追加指定）

一覧は見出しと保存ボタンだけにし、詳しい説明は詳細画面へ載せます。従来の「短い解説」を数文だけで終わらせず、本文3項目の合計は**600〜900字程度を目安**にします。確認できる情報が少なければ短くて構いません。件数や文字数を埋めるための推測・同じ内容の言い換えは加えません。

- summary（何が起きた）：250〜400字目安、最大600字。誰が・いつ・何を発表または決定したか、具体的な変更点、対象・時期・条件を、確認できた範囲で説明。用語は初出で短く説明する。
- whyItMatters（背景と、知っておきたいこと）：150〜250字目安、最大400字。背景や従来との違い、なぜ注目するのか。事実と説明・解釈を区別する。
- impact（自分にはどう関係する）：150〜250字目安、最大400字。家計・仕事・投資・暮らし・楽しみへの具体的な関係、次に何を確認するとよいか。未確定の影響は条件付きで書く。売買や個別の法律判断を断定しない。
- cautionは最大300字。決定済み・予定・未確認、情報の時点、実測していない性能等を必要に応じて示す。
- 各項目は1〜2段落に分け、段落間をJSON文字列の\n\nで区切る。HTMLやMarkdownの装飾は入れない。出典は可能なら複数で照合し、取れない本文を読んだ扱いにせず、転載・長い引用で詳しくしない。

毎回この文書を読む既存タスクへ反映する指定で、タスクの新設・更新時刻の変更・AI APIの追加はしません。既存記事は元の確認日時と事実関係を維持し、今回の補足を最新の再取材や新事実の確認として表示しません。

## 確認できた希望

### 優先するニュースの傾向（2026年10月16日に利用者が再指定）

**できるだけSmartNews・日経電子版・Yahoo!ニュースで大きく扱われるような主要ニュースを優先します。** 媒体をこの3つだけに限定せず、6テーマごとに、重要性・国内での話題性・利用者との関係を見て選びます。

- 候補探しでは、可能な範囲で3媒体の公開見出しや検索結果から、その時点の主要な話題を確認する。実際に掲載・掲載位置を確認できた場合は選定材料にする。未確認なのに「掲載されている」「トップニュース」と断定しない。
- 多くの人の生活・家計・働き方・市場に影響する変化、日本企業の大きな動き、重要な政治決定、世界的な重大ニュースを優先する。AIでは注目サービス・モデル・新機能、芸能では日本で話題の芸能人・番組・作品も優先する。
- 同じ出来事を複数の信頼できる媒体が扱っていることは重要度の手がかりにする。ただし、転載元が同じ記事を複数の独立した裏付けとは数えない。
- 選んだ出来事の事実・数字・決定内容は、企業の公式発表や一次資料、信頼できる別の報道でも照合する。資料を取得しやすいことだけを理由に、重要度の低い発表や小規模なブログ記事を中心にしない。
- 小さな雑ニュース、噂、過度な煽り、前回と同じ話題の単純な再掲で件数を埋めない。良い候補が少なければ、各テーマ0〜3件・全体最大18件より少なくする。

SmartNewsの個人向け画面を直接取得できると約束する設定ではありません。有料記事や閲覧制限を回避せず、確認できる公開情報から独自の短い解説と出典を作ります。3媒体の本文転載・全文AI要約を許諾済みにはしません。

読む本人にとって関心が持てるニュースを、6カテゴリーにそろえます。利用者が関心を持てない雑多な話題で件数を埋めません。「身近」は暮らしの小さな話だけを意味せず、新しいAI、日本企業や市場、世界的な大事件、日本で話題の芸能も含みます。

| カテゴリー | 利用者が取りたいと説明した内容 |
|---|---|
| AI | 仕事に使えるサービス、新機能、新モデル、新しいAIの発表など、AI全般の動き |
| 日本経済 | 物価・税金・給料など自分のお金に影響すること、日本の会社、市場、日本に影響する経済の話 |
| 株式投資 | いま注目されている株式投資に関する話 |
| 国際情勢 | 世界を揺るがしている大きなニュースを中心にする |
| 日本政治 | 日本の政治について知っておくべき重要事項、決定されたこと |
| 芸能ニュース | 芸能人やエンタメなど、日本で話題になっている芸能ニュース |

芸能ニュースは、家計や仕事への実用性だけで評価しません。国内での話題性や楽しさも、利用者の希望に沿う採用理由です。AIも仕事への即効性だけに限定せず、新モデルや新サービスの発表を含めます。

## 次の見本を選ぶ際の案

以下は利用者の説明をもとにした具体化案です。採用・除外の正確さは、実際の記事を並べて確認します。

| カテゴリー | 優先する切り口の例 | 見本に添える説明 |
|---|---|---|
| AI | 新サービス・新モデル・新機能、仕事や普段の操作に関係する変更 | 何が新しく、何ができるようになるか。提供開始と発表予定を分ける |
| 日本経済 | 物価・税制・賃上げ、日本企業の重要な動き、金融政策や為替など日本への影響 | 家計・働く人・国内企業や市場にどう関係するか。影響を断定できない場合は推測しない |
| 株式投資 | 注目銘柄・業種、決算、業績見通し、株主還元、市場を動かす材料 | なぜ注目されているか。報道された材料と将来の予想を区別する |
| 国際情勢 | 大規模な紛争、重要な外交合意、選挙結果、世界経済・安全保障に関わる変化 | 何が起き、どの範囲に影響するか。単に海外の出来事というだけでは優先しない |
| 日本政治 | 重要な法案・制度・予算の決定、選挙・政権に関わる大きな変化 | 決定済み・審議中・提案段階を分ける。実施時期が分かれば付ける |
| 芸能ニュース | 国内で注目される芸能人の動き、作品・番組・音楽・イベントの話題 | 誰の何の話題か。発表や取材に基づく事実と、憶測・感想を分ける |

共通の選び方案：同じ出来事の重複をまとめ、新しい事実や進展がある記事を優先します。見出しの強さだけで選ばず、本文の裏付けが取れない話を補って要約しません。古い資料は最新ニュースとして扱いません。条件を満たす記事が少ない日は、関連の薄い記事を足して件数をそろえません。

当初の希望する発見元はYahoo!ニュース、ITmedia AI＋、ITmedia NEWS、ITmedia ビジネスオンライン、SmartNews、日経電子版です。その後、媒体を固定せず複数サイトを調べる方針に利用者が同意しました。ただし、**日経電子版やSmartNewsで読むような、その時点で押さえておきたいニュースを知りたい**という希望は維持します。発見元・取得方法・要約の出典の利用条件は別に確認します。行政資料やブログが取得しやすいことだけを理由に、それらを中心に選ぶことはしません。

[6カテゴリーの実記事候補と取得経路の調査](6カテゴリーのニュース取得候補調査.md)に、今回見つけた話題と確認できなかった点を記録しました。調査対象を広げたことは、本番へ新しい媒体を追加したことを意味しません。

## 現在の選定への反映

専用クラウドタスクは、毎回GitHub mainのこの文書を読んでからニュースを選ぶ指示です。今回の3媒体重視の希望は、この参照文書を更新して次回の選定へ反映します。毎日8:00・各テーマ0〜3件・全体最大18件は維持します。

`src/model.mjs`の`classify`は旧RSS用のキーワード分類で、現在のクラウドによるニュース選定の実行役ではありません。指定6媒体のRSSや本文取得・本文AI要約は利用条件確認中で無効のままです。現在はChatGPTが公開情報を調べ、選定・独自解説・出典を作り、GitHub Actionsが配信します。

この優先順位は選定の指示であり、全記事が3媒体に載ったことや、人による全件確認を保証する表示にはしません。今後、実際の日次出力を見て、話題の重要性・身近さ・重複・テーマの偏りを確認し、利用者の反応に合わせてこの文書を更新します。
