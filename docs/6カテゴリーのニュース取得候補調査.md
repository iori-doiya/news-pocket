## 4. このサイトで勧める構成と、残る判断

**記事の選定は報道の重要ニュースを基準にし、要約の有無で選定をゆがめない**方針を勧めます。

1. 条件が確認できたRSS・検索データなどから、見出し・URL・日時・媒体名を取得する。
2. 6カテゴリーとの関連、出来事の重複、新しさ、複数の独立した報道での扱われ方を確認する。同一配信記事の転載を複数の独立取材と数えない。
3. 記事の取得・表示が認められる範囲でニュース一覧を作り、元記事へ移動して詳しく読めるようにする。リンクであってもカードに転載する文章・画像の範囲は別に確認する。
4. 本文取得・AI入力・要約の公開まで認められた記事だけにAI要約を付ける。ほかの出典を使う場合は同じ出来事かを確かめ、発見元と実際の要約出典を分ける。

これは推奨する次の構成であり、まだ実装・公開した仕組みではありません。無料で利用条件を満たす発見経路、記事の選定精度、6カテゴリーの継続的な記事量は未確認です。今回、**費用0円で安定稼働する本番の全文AI要約経路は新たに確認できませんでした。** 選定例は見つかったので、次は上記1の発見経路を検証する段階です。媒体への問い合わせは送っていません。

ブログの数を増やすことだけでは、日経やSmartNewsで知りたいような主要ニュースの網羅、取材の深さ、無料再利用の条件は保証できません。読みたい話題を優先し、利用できる範囲を個別に広げます。
