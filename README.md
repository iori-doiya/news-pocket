既存サイトの記事一覧を見出しと保存ボタンだけの表示へ変更しました。詳細を開くと、要点・重要な理由・自分への影響・出典が読めます。Googleログイン・あとで読む・非公開問い合わせは維持しています。

毎日更新は **ChatGPTのクラウドで調査・選定・解説 → 公開GitHubへJSON保存 → GitHub Actionsで検査・送信 → 既存Workers・D1へ反映** する方式です。PCの常時起動は不要です。専用タスクは有効、既存の「朝の重要ニュース」は変更していません。[接続・運用手順](docs/ChatGPTの毎日更新・運用手順.md)と[最新の検証結果](docs/実装・検証報告.md)を参照してください。

**Tavilyの検索キーは不要です。** 検索API方式は試作後に採用を取りやめ、実行コードと登録スクリプトを外しました。本番もChatGPT方式へ切り替え済みです。今回の毎日更新ではWorkers AIも呼びません。既存の本文要約用AI基盤と1人30件・全体50件の保護は維持しますが、指定6媒体のRSS・本文AI利用は条件確認中で無効のままです。財務省・金融庁・Global Voices・arXivを再追加しません。

## PCで起動・終了

このフォルダの **start.cmdをダブルクリック**。Ready onが出たら[http://localhost:8787](http://localhost:8787)を開きます。終了は起動した画面で**Ctrl+C**。PCを再起動した後は再度start.cmdを起動してください。ローカルは架空のサンプル6件で、Google・外部AI・収集は無効です。

Node.js 24を使います。このPCでは起動スクリプトが同梱の24を検出します。他のPCは24 LTSを用意してください。PowerShellで操作する場合：

```powershell
cd "C:\Users\ユーザー\OneDrive\ドキュメント\news-pocket"
npm ci
npm run db:local
npm run dev
```

## 公開・更新

Cloudflare Workers・D1・Workers AI、Google OpenID Connect、GitHub Actionsを使用。公開URLはhttps://my-news-pocket.com。WorkersはFreeのままです。ドメインだけは本人が年額費用を承認して取得し、今回10.46米ドル・自動更新オン。11月1日以降の通常料金は11.17米ドルへ改定予定で、翌年は更新時の料金です。コードのGitHub保存だけではWorkerプログラムは更新されません。当日の編集便JSONはActionsで記事データへ反映します。[初回push実行の成功](https://github.com/iori-doiya/news-pocket/actions/runs/38771752234)を確認済みで、同じ6件が重複しないことも確認しました。朝の記事作成とscheduleの実績とは区別します。サイトの閲覧はPCを止めても可能です。

news-pocketフォルダで `npm run db:remote` → `npm run check` → `npm test` → `npm run build` → `npm run deploy`。既存D1を再作成しないでください。上限移行は0005、編集便は0006です。検索API試作の0007・採用取りやめの0008も移行履歴に残しています。許諾未確認の6媒体を有効にして公開しないでください。

無料枠の保護は維持します。失敗を含む最大50試行、UTC日に7,500 Neuronsの保護用予約、新規1試行150。記事8,000文字・出力900トークン・固定モデルQwenを維持。実際の利用量や失敗、UTC日と日本時間の違いによって50成功より前に停止する場合があります。既存の要約を読むだけでは回数を消費しません。現在は許諾確認中のため新規生成できません。

秘密はCloudflare SecretsとGitHub Actions Secretsへ登録済みで、公開コードへ含めません。問い合わせは運営者専用受信箱で読み、自動メール通知はありません。
